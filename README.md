# Joel Williams Mathew — Nebula Neon Portfolio

Cinematic, futuristic single-page portfolio for Joel Williams Mathew (AI/ML Developer).

## Run it
Open `index.html` in your browser — no build step needed.
Or serve locally:
```
python -m http.server 8000
```
Then visit http://localhost:8000

## What's inside
- Animated starfield canvas + nebula gradients + aurora
- Typed role animation, scrolling tech marquee, magnetic buttons
- 3D tilt project cards with spotlight hover
- Skill bars, counters, scroll reveal, custom cursor
- Theme switcher: Nebula / Neon / Sunset (saved in localStorage)
- Cinematic journey image: `assets/cinematic-journey.png`
- Hero portrait: `assets/joel-profile.jpg` (replace file to change photo)

## Sections
Hero → About → Projects (4) → Journey → Contact
Projects: A World Away, Plant Disease Intelligence, RAG AI Agent, Emotion Detection.

## Edit
All content is in `index.html`. Styles in `style.css`, effects in `script.js`.
